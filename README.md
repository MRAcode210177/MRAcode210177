### 👋 About Me

I'm an IT undergraduate at the **University of Colombo School of Computing (UCSC)**, pursuing a BIT while building production software for real clients. I got into programming because I like watching an idea become something a real user actually touches — that's what pulled me from writing code for coursework into shipping a commercial SaaS product with a live client. I'm working toward becoming a well-rounded full-stack engineer who's equally comfortable designing a clean UI and architecting the backend that powers it.

### 🔭 Currently

- 🏗️ Building **Algo Retail** — a client-facing SaaS + desktop POS system
- 🧱 Architecting a **multi-tenant SaaS platform (AURA)**, deepening my grasp of Spring Boot, MongoDB, and enterprise-grade system design
- 📘 Learning **Spring Boot** and **Jakarta EE / enterprise Java architecture** in depth
- 🎯 Open to **internship and collaboration opportunities** where I can learn from experienced engineers and contribute real value
